소프트바디 2048 머지 + 블록 집꾸미기. 지금은 블록 땅 프로토타입이에요.

## 변경 기록
새로 고친 내용은 날짜별로 여기에 맨 위부터 적어요.

### 2026-11-24
- **굴뚝 연기** — 각진 도트 연기 조각 대신 가장자리가 흐린 둥근 연기(화면을 향하는 그림) 8개, 올라가며 부풀고 부드럽게(smoothstep) 나타났다 사라짐. 밤엔 회색빛
- **배경 구름(임시)** — 자연 에셋 구름 모델(Cloud_Small/Medium/Large)을 섬 아래쪽과 아주 먼 곳에 깔고 천천히 흘려보냄(끝까지 가면 반대편에서 다시). 섬을 가리지 않게, 음영 없이 은은하게, 밤엔 어둡게
- **물 블록** — 흐르는 방향 180도 바로잡음(90° → -90°), 살짝 비치게(투명도 0.72) + 하늘 반사(거칠기 0.08)
- **물 블록 낮게** — 물 블록은 다른 블록보다 높이의 40% 낮게 놓여 물가처럼 움푹 (처음 깔 때·땅 편집으로 바꿀 때·반투명 미리보기 모두)
- **BGM** — 뿅뿅거리는 예전 칩튠 12곡(t0~t11) 삭제, 잔잔한 4곡만 (시간대에 맞춰)
- **자연 소리(ASMR)** — 집 안: 모닥불 · 밤에 밖: 풀벌레 · 내 땅에 물 블록이 있으면: 물소리 (천천히 커지고 작아짐). 위 오른쪽 「자연 소리 · 보통」 버튼으로 꺼짐/작게/보통/크게 (assets/asmr/, scripts/asmr.gd)
- **무한 모드** — 목표 게이지·아이템 보상 삭제(아이템이 너무 빨리 쌓임 → 아이템은 스테이지에서만). 반원이 더 예민하게: 꽉 눌림 깊이 7 → 5.5, 차오르는 속도 0.38 → 0.5, 빠지는 속도 0.7 → 0.55
- **무한 모드 렉 원인과 수정**
  - 게임 화면 뒤에서 3D 월드가 그려지지는 않음 (3D 노드 0개) — 원인은 말랑한 몸 물리(GDScript)가 숫자 수에 비례해 무거워지는 것
  - 가장 큰 문제: 프레임이 늦으면 밀린 시간을 따라잡으려 한 프레임에 물리를 최대 3번 → 더 늦어지고 또 밀리는 악순환. 물리가 무거울 땐(6ms↑) 한 프레임 1번만
  - 숫자가 22개보다 많으면 겹침 정리를 2번 → 1번 (물리 25~30% 가벼움, 판 밖 튕김 0)
  - 자동 저장 10초 → 30초 (웹은 저장 때마다 브라우저 저장소를 맞춰 잠깐씩 끊김)
- **땅 편집** — 누르는 순간 놓일 칸에 반투명 민트 블록, 꾹 누른 채 끌면 따라옴(떼면 놓기). 내 땅 바깥 둘레에 민트 테두리
- **물건 꾹 눌러 옮기기** — 꾸미기 창 없이도 놓인 가구·나무·버섯·바위를 꾹 누르면 집혀서 손가락을 따라옴, 떼면 그 자리에(놓을 수 없는 곳이면 반투명). 돌리기·치우기 막대도 함께

### 2026-11-23 (밤 4)
- **홈 UI 다시 배치** — 위 오른쪽에 재화 두 개(젤리 · 보석)를 나란히, 그 아래 「↻ 반대편」. 공방·플레이 시간·오너먼트·펫 소식은 프로필 아래 왼쪽 정렬 작은 알약으로. 가운데 안내 글씨(바닥을 누르면 걸어가요…)는 없애고 튜토리얼·처음 한 번만 말풍선으로 (집 안 안내도 처음 들어갈 때 한 번). 아래 메뉴의 「틀어 두기」 자리에 「퀘스트」(받을 게 있으면 빨간 점), 왼쪽 퀘스트 버튼은 없앰
- **꾸미기 배치 버그 수정**
  - 상자에서 나온 장식이 정해진 자리에 저절로 놓이던 것 → 꾸미기에 보관했다가 원하는 곳에 직접 놓기 (처음 놓을 땐 몰랑이 앞에)
  - 자연 장식을 심을 때 이미 심은 것 근처를 누르면 지워지던 것 → 지우지 않고 골라요
  - 꾸미기 중 놓인 가구·나무·버섯·바위를 화면에서 누르면 골라짐(발밑 민트 고리) → 땅을 누르면 옮기기 · ↻ 돌리기 · 치우기
  - 꾸미기 창이 열려 있으면 화면을 눌러도 아무것도 안 되던 것, 의자 근처를 누르면 의자로 걸어가던 것 수정

### 2026-11-23 (밤 3)
- **홈 이어하기 두 장** — 큰 이어하기 카드를 반으로 나눠 왼쪽 「스테이지」(다음 단계·목표·오늘 남은 입장), 오른쪽 「무한 모드」(최고 점수·하던 판·남은 보상 판). 「틀어 두기」는 아래 메뉴 줄로
- **무한 모드 던지기 제한 삭제** — 양쪽 반원이 다 눌릴 때만 끝남. 위 정보 줄은 「던진 N번」
- **보석(새 재화) + 퀘스트** — 홈 왼쪽에 보석 수와 「퀘스트」 버튼(받을 게 있으면 빨간 점). 퀘스트는 한 줄로 이어지고 깰 때마다 보석
  1. 스테이지 5단계까지 깨기 (보석 30) — 처음 5단계는 입장 횟수 없이
  2. 선물 상자 1번 열기 (보석 20) → 보석 쓰는 곳 안내: 스테이지 입장 +1 = 보석 10개 (단계 목록에서 횟수를 다 쓰면 버튼)
  3. 무한 모드 1판 하기 (보석 20) — 무한 모드 설명
  4. 스테이지 20단계까지 (보석 50)
  5. 방이나 섬 꾸미기: 장식 1개 놓기 (보석 30) — 꾸미기로 데려감
  6. 스테이지 30단계까지 (보석 50 + 바닥 블록)
  7. 땅 편집으로 바닥 바꾸기 (보석 30) — 받은 블록을 골라 둔 채로 땅 편집을 열어 줌
- **새 튜토리얼** — 시작 이야기 → 이름 짓기 → 바로 스테이지로(퀘스트 1). 그 뒤 안내는 퀘스트가 열릴 때마다 몰랑이가 알려 주고 그곳으로 데려감. 예전 안내(무한 모드→상자→벤치→스테이지) 중이던 저장은 퀘스트로 넘어감
- 늦게 열리는 꾸미기 창이 다른 창(퀘스트 안내)을 덮던 문제 수정

### 2026-11-23 (밤 2)
- **튜토리얼 무한 모드 버그** — 안내 중 무한 모드에서 홈으로 돌아오면 「끝까지 해 보라」며 다시 무한 모드로 보내던 문제 수정. 이제 언제 돌아와도 맛보기 선물(젤리 160, 처음 한 번)을 받고 상자 단계로 넘어감. 안내 판 던지기 40번 제한도 없앰(무한 모드 그대로)
- **스테이지 = 아이템 파밍** — 스테이지는 하루 5번 입장(한국 날짜 기준, 처음 안내 1단계는 빼고). 깨면 무한 모드에서 쓸 아이템을 가방에: 첫 클리어 2개 · 다시 깨기 1개 · 별 3개면 +1 (흔들기·되돌리기·뿅망치·기울이기, 70단계부터 ×2 별도). 단계 목록 위·홈 이어하기 카드에 「오늘 N/5」 표시, 다 쓰면 목록으로 돌아가며 안내

### 2026-11-23 (밤)
- **집 화면 자리 유지** — 무한 모드·스테이지에 갔다가 홈으로 돌아와도 몰랑이가 집 앞으로 돌아가지 않고 있던 자리 그대로 (집 안/밖, 카메라 방향·확대까지). 앱을 껐다 켜면 처음 자리

### 2026-11-23 (저녁)
- **무한 모드 목표 게이지** — 무한 모드에도 목표 막대를 보여 줌. 점수가 목표(2,000 · 6,500 · 13,500 · 22,500 …)에 닿을 때마다 흔들기·되돌리기·뿅망치·기울이기 중 하나를 받음(가방에 남아 다음 판에도 씀). 스테이지를 깰수록 목표가 낮아짐(150단계에서 절반) → 「스테이지를 깨면 무한 모드가 쉬워지는」 구조
- 무한 모드에서 아직 단계로 안 열린 아이템도 가방에 있으면 쓸 수 있음 (하루 3번은 열린 아이템만)
- **꾸미기 자유 배치** — 가구(침대·러그·화분·책장·소파·조명·탁자)와 마당 장식(우체통·벤치·가로등)을 카드에서 「옮기기」 → 바닥을 누른 곳으로, ↻ 로 90도씩 돌리기, 치우기. 위치는 집 크기마다 따로 저장. 울타리·벽 액자는 고정
- **반대편 보기 버튼** — 홈 화면 오른쪽 가운데 둥근 버튼, 카메라가 반 바퀴 돎
- **집 들어가기** — 문 앞 칸에 와 있을 때만 집을 누르면 들어감. 멀리서 누르면 문 앞까지 걸어가기만 함(잘못 눌러 들어가던 문제)
- **무한 모드 보상 중복 방지** — 판마다 번호를 붙여서 같은 판 보상은 한 번만 (홈·목록·이어 하기 어디로 나가도). 튜토리얼에서 「받은 젤리」 대신 「가진 젤리 전체」를 보여 줘서 두 번 받은 것처럼 보이던 문구도 고침

## 폴더
- `scenes/main.tscn`, `scripts/main.gd` — 집 앞마당(웹 버전 크리스마스 마을 집 화면을 옮기는 중): 시간 따라 바뀌는 하늘·별·눈, 빨간 지붕 오두막 + 처마 전구 + 굴뚝 연기, 도트 블록 바닥, 몰랑이·햄스터, 웹 버전과 같은 도트 UI
- `scenes/seat.tscn`, `scripts/seat.gd` — 앉는 의자. **SitPoint** = 앉는 자리(파란 화살표 반대쪽을 봄), **ViewCamera** = 앉았을 때 고정되는 카메라
- `scenes/player.tscn` — 몰랑이(임시 상자 모델)
- `assets/blocks/` — 도트 블록 glb 18종 (바닥 편집용)
- `assets/house/cottage.glb` — 웹 버전 꼬마집 모델
- `data/mollang_data.json` — 웹 버전 스테이지 200개·확률·아이템 데이터 (숫자 게임 판 옮길 때 사용)

## 조작
- 바닥 탭 = 몰랑이가 걸어감(집은 돌아서), 의자 탭 = 가서 앉고 그 의자 카메라로 천천히 바뀜, 「일어나기」로 돌아옴
- 끌기 = 화면 이동, 두 손가락 = 확대·축소
- 「땅 편집」 = 바닥 칸을 고른 블록으로 바꾸기(톡 튀어올랐다 내려앉음), ↺↻ 회전은 편집 중에만

## 앉은 시점 카메라 맞추는 법
1. 고닷에서 `scenes/main.tscn` 열기 → `Seats/FrontChair` 선택 (의자 자체를 옮기려면 이 노드를 이동·회전)
2. 오른쪽 위 인스펙터 아래 **Editable Children** 켜기(또는 씬 트리에서 우클릭 → Editable Children)
3. `ViewCamera` 선택 → 3D 화면 위 **Preview** 체크 → 원하는 구도가 될 때까지 이동·회전, 인스펙터에서 FOV 조절
4. 저장하고 GitHub 에 올리면 자동 빌드. 의자를 더 두려면 `scenes/seat.tscn` 을 `Seats` 아래에 끌어다 놓기

## 확인하는 법
- **웹 링크:** main 에 올리면 자동으로 빌드돼서 `https://<아이디>.github.io/<저장소>/` 에 올라가요.
- **APK (베타 때):** GitHub → Actions → build → Run workflow → apk 켜기. 끝나면 Releases 의 `apk-latest` 에서 받아요.
