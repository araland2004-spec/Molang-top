# 누가 펫이야? — 프로토타입 v0.1

친구가 트레이너도, 펫도 될 수 있는 4인 세션 게임. 몰랑탑과는 별개인 새 게임 아이디어를 빠르게 시험해 보려고 만든 **HTML5 한 파일짜리 프로토타입**이에요 (Godot 아님, 브라우저에서 바로 실행).

- 실행: `index.html` 을 브라우저로 열기 (폰·PC 둘 다)
- 지금은 **나 + 봇 3명**. 진짜 4인 온라인은 아직 아님
- `prototypes/.gdignore` 가 있어서 Godot 에디터는 이 폴더를 무시해요

## 한 판 흐름 (약 4~5분)

1. **탐험 (2분 30초)** — 작은 섬을 돌아다니며 재료(열매·돌·깃털)를 줍고, 가운데 작업대에서 아이템을 만들어요
2. **만남** — 몬스터에 닿으면 가장 가까운 친구가 불려와요. 봇이 몬스터와 만나도 내가 불려갈 수 있어요
3. **룰렛** — 둘 중 하나는 **펫**, 하나는 **트레이너**로 랜덤 결정
4. **배틀 (최대 45초)** — 실시간. 이기면 몬스터 레벨만큼 별 + 펫 경험치 + 재료
5. **결전 (최대 60초)** — 시간이 끝나면 별 순위로 팀을 나눠(1·4등 vs 2·3등) 2:2. 팀 안에서 또 펫/트레이너 룰렛
6. **결과** — 별 순위, 각자 펫/트레이너 몇 번 했는지

## 역할

| | 펫 | 트레이너 |
|---|---|---|
| 하는 일 | 직접 움직여서 물기·구르기(무적)·필살 | 지시(공격!/피해!/필살기!) + 아이템 |
| 성장 | 펫 레벨 → 체력·공격력 | 작업대에서 만든 아이템이 트레이너 가방에서 나감 |
| 협동 보너스 | 「공격!」 중 물면 1.5배 · 「피해!」 동안 안 맞으면 게이지 +15 | 펫이 말을 들을 확률 = 친밀도 (50~95%) |

- **필살기는 둘이 같이 써야 나가요**: 게이지는 팀 공유, 트레이너가 「필살기!」를 외쳐야 펫이 쓸 수 있어요 (트레이너가 없으면 게이지가 차면 바로)
- **말 안 듣기**: 봇 펫은 친밀도가 낮으면 낮잠·꼬리 쫓기·킁킁(딴짓)을 해요. 지시를 잘 따르면 친밀도가 오르고, 같은 짝의 친밀도는 그 판 동안 이어져요
- **역할 공평 보정**: 펫을 많이 한 사람은 다음엔 트레이너가 될 확률이 높아지고, 같은 역할 3연속은 안 나와요
- 몬스터는 공격 전에 빨간 경고(원형 내려찍기 · 직선 돌진 · 포자 발사)를 보여주고, 공격 후 「헉헉」 상태일 땐 약점(1.3배)

## 조작

- 폰: 탐험은 화면 아무 데나 끌어서 이동. 배틀에서 펫이면 왼쪽 아래 조이스틱 + 오른쪽 버튼, 트레이너면 지시·아이템 버튼
- PC: WASD/방향키 이동 · J(또는 Space) 물기 · K(또는 Shift) 구르기 · L 필살 · Z/X/C 지시 · 1~4 아이템(작업대 앞에선 만들기) · M 소리

## 테스트용 주소 옵션

- `?fast` 탐험 40초 · `?auto` 내 캐릭터도 봇이 조종 · `?speed=4` 빨리 감기 · `?seed=7` 같은 판 재현
- 예: `index.html?auto&fast&speed=4` 로 한 판 전체 흐름을 구경

## 이번에 정한 것 (대화에서)

- 오픈월드 장기 성장보다 **짧은 세션형**: 판 안에서 성장(재료·아이템·펫 레벨), 판 밖으로는 기록만 남김. 랜덤 역할이 억울하지 않고 4명 모으기 쉬움
- 전투는 2:2(트레이너+펫 vs 트레이너+펫)가 기본, 탐험 중엔 야생 몬스터와 협동전
