# 랭킹 서버 연결 (Supabase)

지금은 서버 없이 **연습 리그**로 돌아요. 이 기기 안의 연습 상대와 겨루고, 화면에 「연습 리그」라고 떠요.
아래대로 하면 진짜 랭킹이 켜져요. 무료 요금제로 충분하고, 웹·안드로이드에서 똑같이 돼요.

## 1. 프로젝트 만들기
1. https://supabase.com 에서 새 프로젝트를 만들어요 (지역: Northeast Asia (Seoul)).
2. **Authentication → Sign In / Providers**에서 **Allow anonymous sign-ins**를 켜요.
   이렇게 하면 계정을 만들지 않아도 기기마다 익명 아이디가 생겨요.
3. **Project Settings → API**에서 아래 두 가지를 복사해요.
   - Project URL
   - anon public key (공개돼도 괜찮은 키예요)

## 2. 테이블 만들기 (SQL Editor에 붙여 넣고 Run)
```sql
-- 주간 리그: 주(W숫자) × 사람마다 한 줄, 이번 주 무한 모드 최고 점수
create table public.league_scores (
  week text not null,
  uid uuid not null default auth.uid(),
  name text not null check (char_length(name) <= 12),
  tier int not null default 0 check (tier between 0 and 5),
  score bigint not null default 0 check (score >= 0 and score < 100000000),
  updated_at timestamptz not null default now(),
  primary key (week, uid)
);
create index on public.league_scores (week, tier, score desc);

-- 오늘의 판: 날짜 × 사람마다 한 줄
create table public.daily_scores (
  day text not null,
  uid uuid not null default auth.uid(),
  name text not null check (char_length(name) <= 12),
  score bigint not null default 0 check (score >= 0 and score < 100000000),
  updated_at timestamptz not null default now(),
  primary key (day, uid)
);
create index on public.daily_scores (day, score desc);

-- 점수는 오르기만 (낮은 점수로 덮어쓰기 막기)
create or replace function public.keep_best() returns trigger language plpgsql as $$
begin
  new.score := greatest(new.score, old.score);
  new.updated_at := now();
  return new;
end $$;
create trigger league_keep_best before update on public.league_scores for each row execute function public.keep_best();
create trigger daily_keep_best before update on public.daily_scores for each row execute function public.keep_best();

-- 누구나 읽기, 쓰기는 내 줄만
alter table public.league_scores enable row level security;
alter table public.daily_scores enable row level security;
create policy "read all" on public.league_scores for select using (true);
create policy "insert own" on public.league_scores for insert with check (uid = auth.uid());
create policy "update own" on public.league_scores for update using (uid = auth.uid());
create policy "read all" on public.daily_scores for select using (true);
create policy "insert own" on public.daily_scores for insert with check (uid = auth.uid());
create policy "update own" on public.daily_scores for update using (uid = auth.uid());

-- 친구: 프로필(친구 코드·이름·프로필 그림)과 친구 사이
create table public.profiles (
  uid uuid primary key default auth.uid(),
  code text unique not null,
  name text not null check (char_length(name) <= 12),
  avatar text not null default 't:1',
  updated_at timestamptz not null default now()
);
create table public.friends (
  uid uuid not null default auth.uid(),
  friend uuid not null,
  created_at timestamptz not null default now(),
  primary key (uid, friend),
  check (uid <> friend)
);
alter table public.profiles enable row level security;
alter table public.friends enable row level security;
create policy "read all" on public.profiles for select using (true);
create policy "insert own" on public.profiles for insert with check (uid = auth.uid());
create policy "update own" on public.profiles for update using (uid = auth.uid());
-- 내가 추가했거나 나를 추가한 줄만 보여요 (한 사람만 추가해도 서로 친구로 보임)
create policy "read mine" on public.friends for select using (uid = auth.uid() or friend = auth.uid());
create policy "insert own" on public.friends for insert with check (uid = auth.uid());
create policy "delete own" on public.friends for delete using (uid = auth.uid());
```

## 친구
- 친구 코드는 내 아이디 앞 8글자예요 (프로필·친구 창에 보여요).
- 「공유」·「친구 초대」로 보낸 링크(`…/Molang-top/?f=코드`)를 받은 사람이 웹으로 열면 자동으로 친구가 돼요. 코드를 직접 넣어도 돼요.
- 랭킹 → 친구 탭: 친구끼리 이번 주 무한 모드 최고 점수.

## 알아 둘 것
- **리그 묶음**: 지금은 같은 리그(브론즈·실버…)에 있는 사람을 이번 주 점수 순으로 최대 100명까지 보여 줘요.
  위 20%는 승급, 아래 17%는 강등이에요. 사람이 많아지면 30명씩 방을 나누는 서버 함수가 필요해요.
- **정산**: 월요일 0시(한국)가 지나고 게임을 처음 켤 때 정산돼요. 순위는 지난주 마지막으로 랭킹을 연 때 기준이에요.
- **치트**: 점수를 기기에서 보내서, 마음먹고 조작하면 막을 수 없어요. 커지면 판 기록(던진 순서)을 서버에서 다시 돌려 검증하는 방식이 필요해요.
- **이름**: 설정 → 이름 바꾸기 (최대 10자). 욕설 거르기는 아직 없어요.
