# 2026-11-23 작업 일지

웹: https://araland2004-spec.github.io/Molang-top/ · 테스트 브랜치: `/ara/`, `/gunsoon/`

## UI · 화면
- **UI 리뉴얼 v4 적용** — 유리 패널·민트 라인 스타일, 새 아이콘(낮/밤), Poppins·Noto 폰트, 상단 바·정보 줄·목표 바·결과 카드·스테이지 지도(10판씩 챕터)
- 플레이 화면 **판·숫자 몰랑이는 예전 모양으로 되돌림** (UI v4 는 유지, 숫자 글씨 선명하게)
- 화면 비율별 UI 크기·배치(폴드·가로 모드), 간격 줄이고 가로 화면은 폰 폭 기둥으로
- 꾸미기 모델 카드 UI, 편집 중엔 바닥만 보이기
- 설정: 처음부터 새로 하기 · 튜토리얼 다시 보기

## 기능
- **3D 선물 상자** — 끌어서 돌리면 빙글 돌다가 팡 열림 (도감 상자·블록 뽑기 공용)
- **블록 뽑기 · 땅 넓히기** — 새 블록이면 땅 +6, 중복이면 +2 / 내 땅 바로 옆 칸만 넓힐 수 있음
- 집 보상: 오너먼트 보상 고르기, 트리 완성, 펫 선물, 편안함
- 마당 첫 시작은 한 톤 바닥 + 집만, 자연 에셋은 상자 보상으로
- 몰랑이 안내(체험형 튜토리얼), 잔잔한 BGM, 난이도 곡선 조정
- **이동 클릭 이펙트** — 바닥을 누르면 링이 퍼지고 반짝이가 튐

## 조명
- ACES 톤매핑, 환경광·안개 낮춤 (희뿌연 화면 개선)
- 3점 조명(해 + 채움광 + 림), 하늘 환경광/반사, 블룸(밤), 그림자 진하게, 몰랑이·나무·의자 접지 그림자
- **자연 에셋 재질 수정** — 이미션 텍스처 바탕이 회색이라 모든 면이 빛나 그림자가 지워지던 문제 → 낮엔 이미션 끄고 밤에만 은은하게, 금속값 낮춤
- 낮 과노출(잔디색 날아감) 수정
- 채움광이 카메라를 따라가서 **블록 옆면이 시커멓던 문제** 해결

## 버그 수정
- 바닥 탭·집 탭이 안 먹던 문제 (하늘 레이어가 터치를 가로챔)
- 화면 바뀔 때 터치가 다음 화면으로 새던 문제
- 땅 편집에서 블록을 바꾸면 땅속으로 꺼지던 문제
- 상점 ×2 별이 안 열리던 문제
- 야간 QA 버그(물리·점수·스테이지·조작·펫·진동) 반영, 상자 스와이프·×10 열기, 버튼 눌림 효과
