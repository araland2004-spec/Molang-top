# 몰랑탑 UI 리소스 v4

이미지 시안(mockups 폴더)을 그대로 개발할 수 있게 정리한 묶음이에요. 기준 화면은 360×780(논리 px)이고, 실제 기기에서는 이 비율대로 늘리면 돼요.

## 폴더

| 폴더 | 내용 |
|---|---|
| `mockups/` | 화면 시안 7장 (2배 해상도 PNG) |
| `icons/svg_night` · `svg_day` | 아이콘 16개, 밤·낮 색 입힌 SVG |
| `icons/svg_currentcolor` | 색 없는 SVG (웹에서 CSS `color`로 칠할 때) |
| `icons/png_night` · `png_day` | 같은 아이콘 PNG @1x(24) · @2x(48) · @3x(72) |
| `frame/` | 메인 화면 전용 둥근 모서리 브래킷 (모서리 4개 + 9-슬라이스 한 장) |
| `fonts/` | Poppins(숫자) · Noto Sans KR(한글, 한글 11,172자 부분집합) |
| `godot/` | StyleBoxFlat `.tres` 12개 + 색·크기 상수 `mol_ui.gd` + 눌림 효과 `press_fx.gd` |
| `web/` | `tokens.css`, 시안을 그린 HTML 원본 `reference_screens.html` |
| `tokens.json` | 색 · 글꼴 · 크기 · 둥글기 전부 |

## 글꼴

- **숫자·영문**: Poppins Bold(700). 점수 38, 결과 점수 52, 단계 번호 36, 젤리 칩 17. 보조 숫자는 Medium(500).
- **한글**: Noto Sans KR. 본문 Regular, 버튼 Medium, 제목 Bold. 가장 작은 글씨는 12px 이상.
- Poppins SemiBold(600)를 쓰고 싶으면 Google Fonts에서 받아 추가하세요. 시안은 Bold로 그렸어요.
- Godot: `fonts/` 파일을 프로젝트에 넣고 FontVariation 또는 테마 기본 글꼴로 지정. Poppins에 한글이 없으므로 Poppins의 Fallbacks에 Noto Sans KR을 넣으면 섞인 문장도 한 Label로 됩니다.

## 화면별 치수 (360×780 기준)

### 메인(홈) — 브래킷은 여기만
- 화면 모서리 브래킷: 26×26, 화면 가장자리에서 12px 안쪽, 선 1.6px #4CC6B1, 모서리 반지름 8.5, 끝 둥글게 (`frame/`).
- 브래킷 사이 위·아래 가장자리: 양끝이 흐려지는 1px 선 (좌우 44px 띄움).
- 왼쪽 눈금: x 20, 1.5px 선을 7px 간격, 높이 84. 오른쪽 점선 자: x 340, 2px 점을 8px 간격.
- 프로필: 왼쪽 40·위 44, 아바타 44×44 반지름 12. 젤리 칩: 오른쪽 40·위 50, 끝까지 둥근 알약.
- 상태 알약: 위 118, 가운데 정렬, 밤 = 검정 55% / 낮 = 흰색 82% 바탕. 그 위(위 104)에 점이 달린 그라데이션 구분선.
- 아래 묶음(좌우 28, 아래 48):
  - 「이어하기」 76 높이, 반지름 16, 등불색 18%→8% 그라데이션 + 1px 등불 40% 선 + 바깥 은은한 빛. 위 테두리에 짧게 빛나는 선, 숫자 앞 세로 점선.
  - 「STAGE」(Poppins Medium 10, 자간 0.16em)과 「45」(Poppins Bold 36)를 **오른쪽 끝에 맞춰** 위아래로 쌓고 간격 3px. 줄바꿈 태그 쓰지 말 것.
  - 무한 모드·틀어 두기 50 높이, 간격 8. 「MENU」 구분선(9.5px, 양쪽 흐려지는 선). 독 아이콘 칸 66 높이 4개.

### 게임
- 브래킷 없음. 배경은 위쪽이 밝은 원형 그라데이션 (#12343A → #0B2125 → #08191C).
- 상단: 점수(Poppins Bold 38) 왼쪽, 소리·집·목록 버튼 42×42 오른쪽. 그 아래 한 줄 정보 「45단계 · 고비 ‑‑ 던지기 31 남음」(점선으로 구분).
- 목표 막대: 위 98, 높이 9, 끝까지 둥글게, 민트 그라데이션 + 빛. 25%마다 세로 눈금.
- 판(원래 모양 그대로): 312×516, 위 모서리 반지름 18, 옆벽 직선, 아래는 V자로 꺾여 평평한 바닥(옆벽 436px 지점에서 바닥 74~238px로).
  - 테두리 1.6px, 위는 밝은 민트 → 가운데 흐리게 → 아래 다시 조금 밝게 세로 그라데이션. 위 테두리 가운데 짧은 하이라이트.
  - 안쪽 16px 간격 점 격자(민트 9%).
  - 선반: 39~72px 띠(민트 5%), 아래 경계는 점선.
  - 끝 반원: 벽 안쪽 반타원(가로 24·세로 28), 선만 + 작은 눈 2개.
  - 판 바깥 양옆 눌림 게이지: 4×120, 반원 높이에 맞춤.
  - 조준: 고른 숫자는 3px 들리고 등불색 링 + 빛, 떨어질 곳까지 둥근 점선과 점선 원.
- 아래: ◀ · 아이템 3개(74 높이, 노란 개수 배지) · ▶. 기울이기 칸은 아이템 칸의 0.62배 너비.

### 숫자 젤리 (몰랑이)
- 동그란 공이 아니라 말랑한 모양. 테두리 2.4px #0B1416, 아래쪽 안쪽 그림자(검정 12%), 위쪽 안쪽 하이라이트(흰색 28%).
- **대기줄**: 높이 25~30의 캡슐(알약). 숫자가 클수록 옆으로 길게 (1·2·4 ≈ 원, 16 ≈ 52, 64 ≈ 78).
- **판 안**: 바닥·벽에 닿은 쪽은 납작하게, 옆 젤리에 눌린 쪽은 찌그러지게. 날아가는 젤리는 진행 방향으로 살짝 늘어남. (물리 엔진이 실제 모양을 만들 테니 렌더링 색·테두리·하이라이트만 맞추면 돼요.)
- 숫자: Poppins Bold, 젤리 크기에 비례(작은 13 → 128은 24), 글자색 #101214.
- 색: 1 #FF5A4C · 2 #FFE14A · 4 #6EF25A · 8 #36F0B4 · 16 #5AA0FF · 32 #B277FF · 64 #FF4FAE · 128 #FF8A3D (256부터는 원래 COLORS 순서 반복).

### 스테이지 지도
- 「이어하기」 카드(96 높이)가 화면의 주 버튼. 10단계씩 챕터 카드, 지금 챕터만 펼침.
- 챕터 왼쪽에 세로 점선 + 위에서 흐려지는 선, 챕터마다 점: 지금 = 등불(빛남), 다 깬 = 청록, 나머지 = 테두리만.
- 단계 칸 40 높이, 반지름 12. 깬 칸 민트 12%, 지금 칸 등불 채움, 고비 판 보라 1.5px 테두리. 잠긴 칸도 숫자는 보이게(흐린 색).

### 결과 카드
- 반지름 24, 위 테두리 가운데 민트 하이라이트 선. 「STAGE 45 · 고비」 양옆에 짧은 그라데이션 선.
- 점수 52, 그 아래 점선 구분선, 보상 칩, 주 버튼 「다음 단계」(등불 채움)만 발광.

### 틀어 두기 모드
- UI 거의 숨김. 위: 곡 이름 + 진행 막대(1px 선 + 빛나는 점), 아래: 시간(Poppins 30) · 세로 점선 · 공방 수입/오너먼트.

## 선 장식 규칙 (레퍼런스 디테일)
- **그라데이션 선**: 1px, 양끝 투명 → 가운데 민트 28%. 구분선에 씀. 필요하면 16% 지점에 지름 5px 점.
- **점선**: 1px dashed 민트 28%. 「선반 경계」「목표 이전 구분」「카드 안 구분」처럼 같은 덩어리 안을 나눌 때.
- **빛나는 짧은 선**: 카드·버튼 위 테두리 가운데 40~60% 길이, 흰빛 → 투명.
- **십자 표시**: 9×9, 1px. 메인 화면 넓은 빈 공간에만 두세 개.
- 한 화면에 장식 종류는 2~3개까지만.
