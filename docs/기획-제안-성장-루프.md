# 몰랑탑 기획 제안 — 오래 할 이유와 「처음엔 빡빡, 갈수록 팍팍」 곡선

작성: 2026-11-23 새벽 QA 중 (봇 플레이 측정값 포함). 2장의 「연속 합치기」「판 기세」는 이번에 구현했고(브랜치 `claude/ui-game-screen`), 3장부터는 아직 제안이에요. 표의 숫자는 시작값이고, 봇으로 다시 재서 맞추면 돼요.

## 1. 지금 구조의 문제

| 시스템 | 지금 하는 일 | 게임(숫자판)에 주는 영향 |
|---|---|---|
| 스테이지 | 깰수록 무한 모드 아이템·던지기 수 해금 | 있음 (유일한 연결) |
| 젤리 → 선물 상자 → 가구 → 도감 | 집 꾸미기, 도감 다 채우면 집 커짐 | **없음** |
| 오너먼트(플레이 30분마다) → 트리 닦기 → 요정 | 꾸미기 | **없음** |
| 펫(20단계, 집 커지면 쌍둥이·강아지/고양이) | 집에서 돌아다님 | **없음** |

꾸미기·오너먼트·펫이 숫자판과 끊겨 있어서, 스테이지를 다 깨고 나면 「무한 모드를 계속 할 이유」가 최고 점수 하나뿐이에요. 또 무한 모드 점수는 처음부터 끝까지 같은 규칙이라, 오래 키운 사람과 처음 온 사람의 체감이 같아요.

**목표:** 집에서 모은 것들이 무한 모드에 **작고, 눈에 보이고, 상한이 있는** 보너스를 줘서 「처음엔 점수 내기 힘들다가 키울수록 팍팍 올라가는」 곡선을 만든다. 스테이지는 퍼즐 밸런스를 지키려고 편의 기능만 받는다.

## 2. 점수 뼈대 (오늘 넣은 것 + 다음 단계)

오늘 넣은 것: **연속 합치기.** 던진 숫자가 뭔가와 합쳐질 때마다 +1, 헛던지면 0. 점수 = 숫자 × 연쇄 × (1 + 0.5×연속), 최대 ×5 (스테이지는 ×2). 던지기 단위라서 빨리 막 던져도 이득이 없어요.

봇 측정 (무한 모드, 같은 시드):

| | 512 만들 때 | 2048 만들 때 | 던지기당 점수 |
|---|---|---|---|
| 예전 규칙 · 조준 봇 | 4,506 | 39,640 | 302 |
| 연속 합치기 · 조준 봇 | 5,874 | 56,155 | 488 |
| 예전 규칙 · 막 던지기 봇 | 4,918 | (145번째에 끝) | 72 |
| 연속 합치기 · 막 던지기 봇 | 6,886 | (145번째에 끝) | 103 |

- 2→2단계마다 점수가 대략 8~10배라서, 조준 봇 기준 8192는 30만~50만 근처예요. 사람은 봇보다 연쇄가 적으니 **집 보너스(아래)까지 키운 사람이 30만에 닿는** 정도가 목표치로 맞아요.
- 막 던지기는 던지기당 점수가 조준의 1/5 수준이고 금방 끝나서, 「막 던져서 점수가 쌓이는」 문제는 없어요.

**판 기세 (오늘 넣음, 무한 모드만):** 한 판 안에서 처음으로 512·1024·2048·4096·8192를 만들 때마다 그 판 점수 +10% (최대 +50%). 큰 숫자를 만들어야 오르니 막 던지기로는 안 오르고, 판 초반은 빡빡하다가 후반에 팍팍 올라가요.

연속 합치기 + 판 기세를 같이 켠 뒤 다시 잰 값: 조준 봇 2048 때 **58,505점**(예전 규칙 39,640점보다 +48%), 던지기당 417점. 막 던지기 봇은 던지기당 148점에 185번째 던지기에서 끝. 2단계마다 약 8~10배 + 기세를 넣어 계산하면 사람 기준 8192 무렵 25만~35만 점대가 나와요 (예전에 재밌었던 30만 근처).

## 3. 집이 게임에 주는 것 — 「집 보너스」

원칙: 무한 모드에만, 하나하나는 작게, 합쳐서 상한, 화면에 「집 보너스」 칩으로 보여 주기(눌러 보면 어디서 왔는지 목록).

### 3-1. 펫 = 연속·연쇄 성격 보너스 (캐릭터마다 다르게)

| 펫 | 이름 붙은 능력 | 효과 | 함께한 날로 성장 |
|---|---|---|---|
| 햄스터 | 볼주머니 | 연속 합치기가 끊길 때 **1번 지켜 줌** (판마다) | 7일째 2번, 30일째 3번 |
| 쌍둥이 햄스터 | 볼주머니 ×2 | 위와 합산 | — |
| 강아지 | 물어 오기 | 연쇄 상한 10 → 12, 연쇄 소리 한 칸 더 | 30일째 14 |
| 고양이 | 꾹꾹이 | 양쪽 반원 게이지가 10% 느리게 참 | 30일째 15% |

- 펫을 누르면 나오는 말풍선(오늘 넣음)에 능력을 섞어 보여 주면 자연스러워요: 「햄찌 · 볼주머니 채우는 중 (연속 지킴 2)」.
- 「함께한 날」이 이미 있으니 매일 들어올 이유가 생겨요(출석 보상 대신).

### 3-2. 꾸미기·도감 = 기본 점수 등급

| 모은 것 | 보너스 |
|---|---|
| 가구 1개 모을 때마다 | 무한 모드 기본 점수 +1% |
| 도감 한 쪽(실내/실외) 다 채움 | +5% 추가 |
| 집이 커짐(1권 완성) | 무한 모드를 **연속 1** (×1.5)로 시작 |
| 2권부터 (준비 중) | 같은 규칙으로 이어서, 집 레벨마다 시작 연속 +1 (최대 3) |

꾸미기를 할수록 「점수 공방」이 넓어지는 느낌. 상자 중복 3개 교환도 그대로 의미가 생겨요.

### 3-3. 오너먼트·트리·요정 = 아이템 충전

| 모은 것 | 보너스 |
|---|---|
| 요정 1명 | 무한 모드 아이템 하루 무료 횟수 +1 (요정이 고른 아이템, 최대 +3) |
| 트리 닦기 단계 | 다 닦은 날엔 무한 모드 첫 판 「흔들기」 1번 무료 |

플레이 시간 30분마다 오너먼트 → 요정 → 아이템이라, 오래 할수록 무한 모드가 덜 빡빡해져요.

### 3-4. 상한과 표시

- 집 보너스 전체 배율 상한 ×2 (연속·연쇄와 곱해서 최대 ×10 안팎). 랭킹이 생기면 「집 보너스 없는 순수 기록」도 따로.
- 게임 화면 정보 줄에 「집 +18%」 칩, 결과 카드에 「집 보너스로 +12,400」 한 줄.

## 4. 스테이지 쪽 (퍼즐 밸런스 유지)

- 집 보너스는 스테이지 점수엔 안 붙음. 대신 펫 능력 중 **편의형**(햄스터 연속 지킴)만 스테이지에서도 1번.
- 오늘 고친 것: 중복 3단계 제거(197단계), 시작 숫자가 벽에 박히던 21단계, 재료가 모자라던 만들기 단계 45개(배우는 구간 1~40은 1.3배 여유), 점수 목표가 튀던 19단계.
- 고비 판(25·30·35…)은 지금처럼 「아슬아슬」 유지. 대신 고비 판을 깨면 상자/젤리 보상을 2배로 해서 도전할 이유를 줌.

## 5. 오래 할 이유 (매일·매주)

1. **오늘의 부탁 3개** (몰랑이가 말풍선으로): 「연속 5번 이어 가기」 「1024 만들기」 「아이템 없이 2048」 → 젤리. 펫·요정 보너스를 쓰게 유도.
2. **주간 최고 기록**: 무한 모드 이번 주 최고 점수를 집 벽 액자(가구)로 남김 → 꾸미기와 연결.
3. **틀어 두기 모드** (시안 out_06에 있고 아직 없음): 켜 두면 공방 젤리·오너먼트 시간이 흘러감. 「오래 켜 둘 이유」.

## 6. 만드는 순서 (추천)

1. 집 보너스 칩 표시 (규칙만, UI 작음) → 봇으로 8192 점수 다시 재기 (판 기세는 이미 넣음)
2. 펫 능력 3종 (햄스터 먼저: 연속 지킴)
3. 도감 % 보너스 + 집 레벨 시작 연속
4. 요정 → 아이템 충전
5. 오늘의 부탁, 틀어 두기 모드

규칙 숫자는 전부 `mollang_data.json`에 `perks` 표로 두면 코드 안 고치고 맞출 수 있어요.

## 8. 오너먼트·꾸미기·「오래 있으면」 보상 — 정리 제안

### 지금 오너먼트의 문제

- 플레이 30분마다 1개 → 트리에서 닦아 달기 → 요정. **보상이 꾸미기뿐**이고, 10개를 다 달면 그다음엔 아무 일도 없어요.
- 「플레이 시간」은 앱이 켜져만 있어도 쌓여서, 사실상 「오래 켜 둔 보상」이에요. 의도(오래 있으면 보상)와는 맞는데 받는 게 없어요.
- 젤리(공방)도 같은 「켜 둔 시간」 보상이라 둘이 겹쳐요.

### 추천: 오너먼트는 빼지 말고 「시간 보상 상자」로 바꾸기

트리는 크리스마스 마을 콘셉트의 중심이고, 「30분마다 하나씩 달린다」는 그림이 오래 있었다는 기록으로 딱 좋아요. 대신 받는 게 있어야 해요.

| 단계 | 지금 | 바꾸면 |
|---|---|---|
| 30분마다 오너먼트 | 닦아서 달기 | 그대로 (손맛) + **달 때 보상 하나 고르기**: 젤리 50 · 무한 아이템 1개 · 블록 상자 열쇠 |
| 10개 다 달면 | 끝 | **트리 완성 → 요정 + 영구 효과**: 공방 수입 +10% (트리마다) |
| 그 뒤 | 없음 | **계절 트리**: 다음 트리(눈꽃·벚꽃·여름…)가 새로 시작. 끝없이 이어지는 장기 목표 |

- 하루 상한: 오너먼트 보상은 하루 최대 6개(3시간)까지만. 켜 두기만 해서 무한히 버는 걸 막아요.
- 요정은 계속 집을 날아다니고, 누르면 「이번 트리에서 받은 것」을 알려 줘요.

### 꾸미기 = 「집 편안함」 → 공방 배율

꾸미기에 직접 보상을 붙이면 「예쁘게」보다 「많이」 놓게 돼서, **편안함 점수**로 묶는 게 좋아요.

| 편안함에 들어가는 것 | 점수 |
|---|---|
| 놓아 둔 가구 1개 | +3 |
| 넓힌 땅 1칸 | +1 |
| 함께 사는 펫 1마리 | +10 |
| 완성한 트리 1개 | +10 |

- 편안함 0~100 → 공방 수입 ×1.0 ~ ×2.0. 홈 화면 상태 알약에 「편안함 64」 표시.
- 꾸미기 창에 「이걸 놓으면 편안함 +3」처럼 바로 보여 줘서 꾸미는 이유가 눈에 보이게.

### 「오래 있으면」 = 펫이 선물을 물어 와요

집 화면(또는 틀어 두기)에 머무는 동안 펫이 가끔 선물을 물고 와서 집 앞에 놓아요. 눌러서 받기.

- 20분마다 1번, 하루 최대 3번. 내용: 젤리 20~50 · 무한 아이템 1개 · 가끔 가구 조각.
- 펫마다 성격대로: 햄스터는 젤리, 강아지는 블록, 고양이는 아이템을 잘 물어 와요.
- 「함께한 날」이 길수록 선물이 조금 좋아짐 → 매일 들어올 이유.
- 효과: 꾸미기(펫이 돌아다닐 마당) · 오래 있기 · 펫 세 가지가 한 번에 묶여요.

### 우선순위

1. 오너먼트 달 때 보상 고르기 + 하루 상한 (코드 작음, 바로 체감)
2. 펫 선물 (오래 있을 이유, 펫에 의미)
3. 편안함 점수 → 공방 배율 (꾸밀 이유)
4. 트리 완성 영구 효과 + 계절 트리 (장기 목표)

빼는 쪽을 고른다면: 오너먼트·트리를 통째로 빼고 「플레이 시간 보상」을 펫 선물 하나로 합치는 게 가장 단순해요. 다만 트리는 지금 집 안의 중심 장식이라, 빼면 집 안이 허전해지고 크리스마스 마을 느낌도 약해져요. 그래서 **바꿔서 살리는 쪽**을 추천해요.
